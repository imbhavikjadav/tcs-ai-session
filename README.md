# AI Demo — Two Builds, One Season

A showcase site for two products built with Claude Code: **LegalClear** (a Claude-API-powered legal
document analyzer) and **FreightNexus** (an AI-built pan-India trucking marketplace).

Live at: https://imbhavikjadav.github.io/tcs-ai-session/

Built as a single static HTML page (`index.html`) with real screenshots captured from live local/production
runs of both apps — see `screenshots/legalclear/` and `screenshots/freightnexus/` for the source images and
their manifests.
